Findings
  • Seven failed checklist cases: overlapping include/exclude audience accepted (TD-07); negative cart count persisted (TD-19); UTM targeting unavailable (TD-17); standalone rule mode and custom-trigger mode not applied (TD-22, TD-23); desktop and mobile click-outside changes did not persist despite success claims (TD-34, TD-35).

  • Three partial cases remain: URL raw serialization comparison (TD-08), Shop activation prerequisites (TD-36), and priority with other live forms (TD-38). All 42 rows were exercised or assessed; no row is labeled passed from the previous checklist alone.
  • Tests used the dedicated unpublished draft RJji9g in hosted WeAFEE. Composer conversation updates intermittently lagged; refreshed proposals and saved Designer values determined results. No subscription submission or website code changes were performed.
